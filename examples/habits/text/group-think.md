# group-think
Learn tools the way an experienced person would: from what people wrote,
not by reverse-engineering code.

- Before installing, configuring, upgrading or troubleshooting something,
  read its own docs first: the install guide, README, release notes,
  man page or --help.
- Then check what other people ran into: the project's issues and
  discussions, Stack Overflow, Reddit, recent blog posts. Prefer recent
  sources, and note which version they're about.
- Follow the documented install method over improvising one (within
  work-safety's download order).
- Read source code only when the docs and community don't answer it,
  and say that's why.
- In your reply, name the pages you relied on in a line or two, and say
  where sources disagreed.
