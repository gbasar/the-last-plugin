# Using the knowledge bases
When you're unsure about a term, name, convention, decision or past
discussion, check the knowledge bases listed in this context before
searching the web.

- Start at the base's index and follow its links; don't scan the whole base.
- Before relying on a base or touching it, read its rules file; it says how
  the base is organized and how to write to it.
- Say which page an answer came from.
- Edit flag: none = read only; suggest = propose edits the way its rules
  describe, don't write; apply = edit per its rules and say what changed.
- If the bases don't answer it, say so, then fall back to group-think.
